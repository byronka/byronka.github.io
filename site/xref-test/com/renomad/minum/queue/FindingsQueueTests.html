51      /**
52       * FINDING 14: stopping an idle ActionQueue leaves {@code isStopped()} reporting false.
53       * <p>
54       *     Defect: {@code src/main/java/com/renomad/minum/queue/ActionQueue.java:126} -
55       *     {@code if (queue.isEmpty()) return;} sits inside the wait loop and returns
56       *     <em>before</em> {@code isStoppedStatus = true;} on line 130.  In other words the
57       *     clean shutdown path - the queue drained, nothing left to do - is exactly the path
58       *     that never records that the queue stopped.  {@code isStoppedStatus} is only ever set
59       *     on the path where the queue is still not empty after all the retries, i.e. the
60       *     failure path.
61       *     <br>
62       *     The consequence shows up in logging.  {@code Logger.logHelper}
63       *     ({@code src/main/java/com/renomad/minum/logging/Logger.java:134}) chooses between
64       *     printing directly and enqueuing based on {@code loggingActionQueue.isStopped()}.
65       *     Because a cleanly-stopped queue still answers false, every log line emitted after
66       *     shutdown takes the enqueue branch, where it is dropped rather than printed - so the
67       *     log messages from the end of a shutdown, precisely the ones that matter when a
68       *     shutdown goes wrong, are silently lost.
69       *     <br>
70       *     Note that {@code stop(0, 0)} hides the defect, because with a count of zero the loop
71       *     body never runs and the assignment is reached.  Production code calls the no-argument
72       *     {@code stop()}, which is {@code stop(5, 20L)}.
73       * </p>
74       * <p>
75       *     Correct behavior: after {@code stop()} returns, {@code isStopped()} must report true,
76       *     whether the queue drained cleanly or was crashed closed.
77       * </p>
78       * // BK: Fixed by setting isStoppedStatus to true when the queue is empty.
79       */
80      @Test
81      public void test_Finding_StopSetsStoppedStatusOnCleanPath() {
82          var actionQueue = new ActionQueue("FindingsQueueTests action queue", context).initialize();
83  
84          // the queue is idle, so this is the clean shutdown path
85          actionQueue.stop();
86  
87          assertTrue(actionQueue.isStopped(),
88                  "after stop() returns on an idle (already drained) ActionQueue, isStopped() must report true.  " +
89                          "It reported false, because the 'if (queue.isEmpty()) return;' guard inside the wait loop " +
90                          "returns before isStoppedStatus is assigned.  Logger.logHelper keys off isStopped(), so a " +
91                          "false answer here means every log line emitted after shutdown is enqueued onto a dead queue " +
92                          "instead of being printed.");
93      }
